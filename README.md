# AeroSeat AI v1.0

Учебный веб-прототип для демонстрации автоматизированной рассадки пассажиров и упрощённого анализа продольного распределения массы.

## Возможности
- Генерация учебного набора пассажиров или загрузка CSV.
- Учет групп, которые должны сидеть рядом.
- Жадная эвристика рассадки с балансировкой массы по продольным зонам.
- Сравнение с базовой последовательной рассадкой.
- 2D-карта салона и интерактивная 3D-визуализация.
- Учебная оценка продольного центра тяжести по заданным плечам.

## Важно о модели Airbus A320
В проекте используется **условная учебная геометрия** салона A320: 30 рядов, компоновка 3-3 (180 мест), и условные координаты рядов. Это не утверждённая схема конкретного борта и не эксплуатационная документация Airbus.

Масса пустого самолёта, исходный момент, положение пассажирских рядов и допустимый диапазон CG задаются как демонстрационные параметры. Они не являются реальными данными Airbus A320. Результаты нельзя использовать для загрузки реального самолёта, подготовки load sheet или принятия эксплуатационных решений.

## Запуск
Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

Откройте адрес, который покажет Streamlit (обычно http://localhost:8501).

## Формат CSV
Обязательные поля:
- `passenger_id` — уникальный ID
- `weight_kg` — масса пассажира в кг

Необязательные поля:
- `group_id` — общий ID группы, которую желательно посадить рядом
- `needs_aisle` — `true/false`, приоритет места у прохода
- `preferred_zone` — `front`, `middle`, `rear` или пусто

Пример находится в `data/sample_passengers.csv`.

## Научный эксперимент
Сравните `Sequential baseline` и `AeroSeat heuristic` на одинаковом наборе пассажиров. Зафиксируйте:
1. число выполненных групповых размещений;
2. разброс суммарной массы между передней, средней и задней зонами;
3. учебную оценку CG;
4. время расчёта.

Для корректного исследования запускайте несколько наборов данных с разным случайным seed и сравнивайте средние значения.

## Ограничения
Это учебный демонстратор, а не сертифицированная система. Он не моделирует все ограничения кресел, аварийных выходов, требований accessibility, топлива, багажа, экипажа, эксплуатационных envelope и фактических station arms. Система не подтверждает безопасность реальной загрузки.
